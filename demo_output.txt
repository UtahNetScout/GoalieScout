  Black Ops Goalie Scouting Platform - AI-powered goalie scouting and
  analysis.

Options:
  --version  Show the version and exit.
  --help     Show this message and exit.

Commands:
  add-goalie       Add a new goalie to the database.
  analyze          Analyze a goalie using AI.
  create-blog      Create a blog post spotlight for a goalie.
  generate-report  Generate a detailed scouting report.
  init             Initialize the scouting database.
  list-goalies     List all goalies in the database.
  rank             Rank goalies by performance metrics.
  stats            Display database statistics.
  tweet            Create (and optionally post) a tweet about a goalie.

========================================================================
Quick Start Example
========================================================================

# 1. Install
pip install -r requirements.txt
pip install -e .

# 2. Initialize
goaliescout init

# 3. Add a goalie
goaliescout add-goalie --name "Connor Smith" --country "USA" --dob "2004-03-20" --league "NCAA"

# 4. Generate report
goaliescout generate-report connor_smith --format markdown

# 5. View rankings
goaliescout rank --metric save_percentage
